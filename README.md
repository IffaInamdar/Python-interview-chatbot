# Python-interview-chatbot

## 🤖 Python AI Interview Chatbot

## 📌 Overview

The Python AI Interview Chatbot is an intelligent application designed to help users prepare for Python technical interviews. It simulates a real interview by asking Python-related questions, evaluating user responses, providing instant feedback, and generating an overall performance report.

The chatbot aims to improve users' technical knowledge, communication skills, and interview confidence through an interactive learning experience.

## ✨ Features

* 🤖 AI-powered interview conversation
* 🐍 Python interview questions (Beginner to Advanced)
* 💬 Interactive chat interface
* 📊 Performance evaluation and scoring
* ✅ Instant feedback for each response
* 📈 Final interview summary
* 📝 Personalized improvement suggestions
* 🔄 Multiple interview sessions
* 📂 Clean and modular Python code

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/python-interview-chatbot.git
```

### 2. Navigate to the project folder

```bash
cd python-interview-chatbot
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux/macOS**

```bash
source venv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Configure API Key

Create a `.env` file and add your API key.

```text
OPENAI_API_KEY=your_api_key_here
```

### 7. Run the application

If using Streamlit:

```bash
streamlit run app.py
```

If using Flask:

```bash
python app.py
```

## 🚀 How It Works

1. The user starts an interview session.
2. The chatbot asks Python interview questions.
3. The user submits answers.
4. The AI analyzes the responses.
5. Feedback is provided after each answer.
6. A final score and improvement report are generated at the end of the interview.
